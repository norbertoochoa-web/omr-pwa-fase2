## Problemas Conocidos

1. **Foto comprimida (44KB) no produce buenos resultados OMR** — la imagen de prueba `imagen_mobil.jpeg` está muy comprimida para detectar marcadores finos
2. **Captura desde cámara (getUserMedia)** puede fallar en Chrome incógnito → usa modo fallback
3. **El TXT genera solo 5 respuestas por línea** — el formato Delphi 7 espera agrupaciones de 5, no las 60 preguntas completas
4. **Los outputs/ se crean como root** (usuario del contenedor) → requieren sudo para borrar

## Arquitectura

```
[PWA Móvil] --fetch--> [FastAPI :8000] --> PostgreSQL
                            |
                    [OMR Engine]
                    CropOnMarkers (CLAHE + template matching)
                    → read_omr_response (threshold dinámico)
                    → EvaluationEngine (score vs respuestas)
                            |
                    [outputs/{institution}/{session}/]
                    original.jpg + marked.jpg + session.txt
```
