## Objetivo
Implementar y desplegar:
1. Borde blanco fijo en rectángulo de cámara
2. Texto guía dinámico 3 estados (Sube/Baja el celular, Mantén quieto, ¡Listo!)

## Cambios Implementados

### camera.js — refactor para guía dinámica
- `detectCorners()` ahora retorna objeto `{ detected, reason, offsetY }` en vez de boolean
- `checkCalibration()` retorna `{ calibrated, guidance }` donde guidance: `alinear`, `subir`, `bajar`, `quieto`, `listo`
- `startCalibration()` acepta nuevo callback `onFrame` que se ejecuta cada frame con estado detallado

### Camera.js — UI + auto-capture
- Borde del rectángulo: `border-overlay-red overlay-transition` → `border-white`
- Eliminado `overlayBorder` y los 4 swaps de clase red/green
- Agregado `<div id="guidance-text">` debajo del rectángulo para texto guía
- Callback `onCalibrationChange` ahora recibe objeto `{ calibrated, guidance }`
- Callback `onFrame` actualiza texto guía cada frame
- Auto-capture: cuando `calibrated=true`, espera 3s de cooldown y dispara `captureBtn.click()`
- Flag `isProcessing` para evitar capturas concurrentes

### style.css + tailwind.config.js
- Eliminado `.overlay-transition { transition: border-color 0.3s ease, ... }`
- Eliminados colores `overlay: { red, green, yellow }`

### portal.py — mostrar originales sin marked
- Ahora itera tanto `_marked.jpg` como `_original.jpg`
- Si un `_original.jpg` no tiene `_marked.jpg` correspondiente, se muestra igual en galería
