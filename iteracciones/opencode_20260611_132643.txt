Asunto: Plan de persistencia de imagenes OMR en VPS

Decisiones tomadas:
- Path base unico para datos: /var/omr/data
- Estructura: /var/omr/data/outputs/<institution_id>/<session_id>/

  - <uuid>_marked.jpg    (imagen con marcadores detectados)
  - <session_id>.txt     (resultados TXT)
- Ambos contenedores (API fase2 y Portal fase3) montan el mismo path
- Acceso web para soporte via /data en el API
